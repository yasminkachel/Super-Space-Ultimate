# Space Defender Ultimate 

**Jogo arcade de tiro espacial** - Proteja a Terra por 2min contra aliens!

##  **Gameplay**
PC: `← → + ESPAÇO` | Mobile: Touch  
**Objetivo**: Sobreviva 2min por fase

**Inimigos** 
🔴 Vermelho (reta, muita vida) | 🔶 **Laranja** (zigzag, média vida)

**Progressão**  
10 fases | 💰 Moedas |  4 upgrades permanentes:  
`🔥 Cadência | 📈 Vel.Tiro | ⚔️ Dano | 🏃 Vel.Nave`

**Recursos**  
 Visual cyberpunk + partículas  
 Áudio procedural  
 PC/Mobile responsivo  
 Save automático

**AVISO:**
vesão mobile esta com problemas de interface, porem funcional a gameplay
